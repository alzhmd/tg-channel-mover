# انتقال‌دهنده‌ی کانال (Channel Mover)

**کپی کامل یک کانال تلگرام در کانال دیگر؛ بدون «فوروارد از»، با آلبوم و کپشن سالم، ایموجی پریمیوم، لینک‌های اصلاح‌شده و قابل‌ادامه.**

[English](README.md) · [معماری](docs/ARCHITECTURE.md) · [محدودیت‌های تلگرام](docs/TELEGRAM_LIMITS.md) · [عملیات](docs/OPERATIONS.md) · [تغییرات](CHANGELOG.md)

</div>

وقتی کانالی قرار است رها یا حذف شود، هم مخاطب و هم محتوا باید جابه‌جا شوند. فوروارد دستیِ هزاران پست روی همه‌شان نام فرستنده می‌گذارد،
آلبوم‌ها را می‌شکند و ایموجی‌های پریمیوم را از بین می‌برد. این ربات تلگرام همه‌ی کار را از طریق منوی دکمه‌ای انجام می‌دهد و بعد از
ری‌استارت یا محدودیت‌های سرعت تلگرام هم ادامه می‌دهد.

برای یک کانال واقعی حدود ۱۴ هزار پستی ساخته و آزمایش شده است: دو کپی کامل، ۸۱ آلبوم، حدود ۶۷ هزار ایموجی پریمیوم و ۹٬۵۰۰ لینک به پست‌های قدیمی، هرکدام با مبدا تطبیق داده شد.

## امکانات

* **بدون نام فرستنده و بدون «Forwarded from»**؛ پست‌ها طوری می‌آیند که انگار خودتان نوشته‌اید.
* **همه‌چیز حفظ می‌شود**: متن، کپشن، فرمت، فایل با هر حجم، نظرسنجی، استیکر، آلبوم، دکمه‌های لینکی و (با موتور پریمیوم) **ایموجی‌های پریمیوم**.
* **ایموجی‌های معمولی خودکار پریمیوم می‌شوند** (اختیاری).
* **لینک‌های داخل پست‌ها که به کانال قدیمی اشاره دارند، به پستِ متناظر در کانال جدید وصل می‌شوند**؛ همان بار اول درست نوشته می‌شود، حتی برای پست‌هایی که هنوز کپی نشده‌اند.
* **هر بازه‌ای**: همه، «از پست فلان تا آخر»، «تا پست فلان» یا «از فلان تا فلان»؛ با لینک پست، شماره یا خودِ پستِ فورواردشده.
* **قابل‌ادامه و امن**: توقف / ادامه / لغو، پایداری در برابر ری‌استارت و خرابی، بدون ارسال دوباره‌ی پست، رعایت دقیق محدودیت سرعت تلگرام.
* **همگام‌سازی زنده**: پست‌های تازه‌ی مبدا بعد از کپی تاریخچه خودکار منتقل می‌شوند.
* **جدول دقیق «شناسه‌ی قدیم ← جدید»** به‌صورت CSV (برای اصلاح لینک‌های بیرونی، فهرست‌ها و ربات‌ها).
* **برگشت**: پاک کردن دقیقاً همان پست‌هایی که یک انتقال ساخته.
* برای هر تعداد کانال قابل‌استفاده؛ لینک دعوت خصوصی هم پذیرفته می‌شود؛ فقط مدیرها دسترسی دارند.

## دو موتور

| | 🤖 موتور ربات | 🌟 موتور اکانت پریمیوم |
|---|---|---|
| روش | `copyMessages` در Bot API | اکانت پریمیومِ شما (MTProto) که با QR وصل می‌شود |
| ایموجی پریمیوم | **از بین می‌رود**؛ تلگرام اجازه نمی‌دهد ربات (حتی با مالک پریمیوم) در کانال بگذارد | **حفظ می‌شود** و ایموجی‌های معمولی هم ارتقا می‌یابند |
| لینک به پست‌های قدیمی | اصلاح نمی‌شود | **حین کپی اصلاح می‌شود** |
| سرعت | حدود ۶۰ پست در دقیقه | به‌طور پیش‌فرض حدود ۶۰ تا ۷۵ در دقیقه (سرعت ایمن) |
| نیاز | ربات ادمین مبدا و مقصد | `TG_API_ID`/`TG_API_HASH`؛ اکانت عضو مبدا و ادمین مقصد |
| نگاشت قدیم ← جدید | گاهی فقط بازه‌ای | همیشه دقیق |

اگر اکانت پریمیوم وصل باشد، ربات به‌طور پیش‌فرض آن را انتخاب می‌کند و می‌گوید انتخاب دیگر چه هزینه‌ای دارد. چرا ربات نمی‌تواند: [docs/TELEGRAM_LIMITS.md](docs/TELEGRAM_LIMITS.md).

## شروع سریع

1. در [@BotFather](https://t.me/BotFather) ربات بسازید و توکن را بردارید. شناسه‌ی عددی تلگرام خودتان را هم پیدا کنید (مثلاً با [@userinfobot](https://t.me/userinfobot)).
2. **تنظیم**: `cp .env.example .env` و `BOT_TOKEN` و `ADMIN_IDS` را پر کنید. برای موتور پریمیوم `TG_API_ID` و `TG_API_HASH` را هم بگذارید
   (از [my.telegram.org](https://my.telegram.org) ← *API development tools*).
3. **اجرا**
   ```bash
   docker compose up -d --build            # یا:  make install && make run
   ```
   (فایل systemd: `deploy/channel-mover.service`)
4. ربات را **ادمین کانال مبدا** (هر دسترسی) و **ادمین کانال مقصد** («ارسال پیام») کنید؛ کانال‌ها خودکار در ربات ظاهر می‌شوند.
5. **فقط موتور پریمیوم**: در ربات «🌟 اکانت پریمیوم ← 🔗 اتصال با QR» را بزنید و کد را در *تلگرام ← تنظیمات ← دستگاه‌ها ← اتصال دستگاه دسکتاپ* اسکن کنید.
   اکانت باید عضو مبدا و ادمین مقصد باشد.
6. «➕ انتقال جدید» ← مبدا ← مقصد ← تنظیمات ← «🚀 ادامه» ← «✅ بله، شروع کن». پیشرفت را ببینید؛ هر زمان می‌توانید متوقف یا لغو کنید.

> رابط ربات فعلاً **فارسی** است.

### تنظیمات هر انتقال

| گزینه | معنی |
|---|---|
| 🌟/🤖 موتور | اکانت پریمیوم یا ربات |
| 📍 از پست / 🏁 تا پست | محدود کردن بازه با لینک، شماره یا پست فورواردشده (خودِ دو پستِ مرزی هم کپی می‌شوند) |
| 🔕 بی‌صدا | بدون نوتیفیکیشن برای اعضای مقصد (پیش‌فرض روشن) |
| 🔄 همگام‌سازی زنده | ادامه‌ی کپی پست‌های تازه‌ی مبدا |
| ✨ ایموجی پریمیوم | ایموجی معمولی ← پریمیوم (موتور پریمیوم) |
| 🔗 لینک‌ها ← همین کانال | اصلاح لینک‌های کانال قدیمی؛ «🏷 نام‌های قدیمی» برای یوزرنیم‌های قبلیِ کانال مبدا |
| 🚫 حذف کپشن / 🔒 محافظت | همان‌طور که نوشته شده |

## سرعت، محدودیت تلگرام و اکانت شما

تلگرام سرعت نوشتن را محدود می‌کند و عددها را منتشر نمی‌کند. `FLOOD_WAIT` یک «کندتر شو»ی معمولی است، نه بن؛ ولی نادیده گرفتنش انتظار را طولانی‌تر می‌کند.
برای همین ربات با سرعت ثابت می‌نویسد (`USER_MIN_INTERVAL` یعنی ۰٫۸ ثانیه برای هر پست)، بعد از هر محدودیت کندتر می‌شود، دقیقاً همان مدت صبر می‌کند
(حتی بعد از ری‌استارت) و انتظارهای بلند را به شما خبر می‌دهد. در کانال بزرگ هر یکی دو ساعت یک انتظار حدود ۲۵ دقیقه‌ای می‌آید (سهمیه‌ی ساعتی ارسال رسانه):
**۱۴ هزار پست حدود ۵ ساعت طول می‌کشد.** تا پایان انتظارِ ارسال، اکانت وصل‌شده در خود تلگرام هم نمی‌تواند پیام بفرستد. جزئیات و اندازه‌گیری‌ها:
[docs/TELEGRAM_LIMITS.md](docs/TELEGRAM_LIMITS.md).

## نکته‌ها

* تاریخ پست‌ها در مقصد **زمان کپی** است (تلگرام اجازه‌ی تغییرش را نمی‌دهد). تا پایان کار مقصد را عمومی نکنید.
* کانال مبدا با «محدودیت ذخیره و فوروارد» قابل‌کپی نیست؛ پست‌هایی که خودِ تلگرام برای همه مسدود کرده (کپی‌رایت) رد و شمرده می‌شوند.
* دکمه‌های لینکی منتقل می‌شوند؛ دکمه‌های «کالبک» فقط داخل ربات سازنده‌شان کار می‌کنند، پس گزارش می‌شوند و کپی نمی‌شوند.
* لینک به مقصدِ **خصوصی** به شکل `t.me/c/<id>/<post>` است و فقط برای اعضای کانال باز می‌شود.
* ویرایش پست‌ها بعداً ممکن است ولی تلگرام فقط حدود ۴ تا ۵ ویرایش در دقیقه می‌دهد؛ برای همین لینک‌ها هنگام کپی نوشته می‌شوند.
* **ویرایش‌هایی که بعد از کپی روی پست‌های مبدا انجام شود منتقل نمی‌شود** (فقط پست‌های تازه). محدودیت ویرایش تلگرام (حدود ۴ تا ۵ در دقیقه) ویرایش انبوه را عملی نمی‌کند.
* فقط روی کانال‌هایی که مالک یا مدیرشان هستید و با اکانت خودتان استفاده کنید. موارد محرمانه: [SECURITY.md](SECURITY.md).
